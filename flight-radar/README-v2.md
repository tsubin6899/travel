# 航旅雷達 v2

開啟 v2.html 使用新版。資料保存於此瀏覽器 localStorage；設定頁支援 JSON 匯出與匯入。

包含新增、編輯、暫停、刪除、狀態篩選、單程／來回、成人數與艙等、日期驗證、目標總價、示意價格走勢、示意比價排序與直飛／行李篩選、站內通知已讀狀態。

首次使用沒有假報價；可主動載入三筆示意旅程。沒有即時 API、背景排程或 Email/Push。機票平台連結目前開啟平台首頁，需要重新輸入條件。
