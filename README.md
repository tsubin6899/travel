# 航旅雷達 Flight Radar

一個可直接在瀏覽器開啟的機票價格監看 App 原型。使用者可建立監看條件、檢視示意比價結果，並前往 Google Flights、Skyscanner 與 Trip.com 確認最終報價。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可使用，不需要安裝套件或啟動伺服器。

## 現有功能

- 建立與篩選機票價格監看
- 顯示目標價達標狀態與價格變動
- 搜尋航線與示意比價
- 開啟 Google Flights、Skyscanner、Trip.com
- 支援手機與桌面版面

## 資料說明

目前畫面中的票價是示意資料，未連接即時報價 API。正式監價需要核准的供應商 API、後端排程與通知服務。
